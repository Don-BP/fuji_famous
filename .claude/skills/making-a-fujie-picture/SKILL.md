# Making a Fujie picture

## Overview

All Fujie artwork is generated by a short Python script in `tools/` that calls
`tools/gen.py`, which posts a prompt (plus any reference images) to the Gemini
image model and writes PNGs into `Fujie_Creative/`. The prompt is the work. The
script is the record of what the prompt was, which is why every picture gets its
own `tools/run_*.py` file instead of a one-off command.

`gen.py` never overwrites. An existing file at the output path is moved into an
`old/` folder beside it with a timestamp, so a bad regeneration can always be
undone.

## When NOT to use

- **Art that has already been approved is never regenerated.** The plush, the
  keychain and the LINE sticker sheets are settled. Regenerating them to "match"
  something else has been tried and thrown away twice.
- The canonical Chibi Fujie master lives in `Fujie_Creative/01_character`.
  Variants are kept, never promoted over the master.

## Steps

1. **Check it does not already exist.** Look in `Fujie_Creative/` for the subject
   folder. If there is a picture there and it was approved, stop.
2. **Copy an existing run script** as the starting point — `tools/run_ideas_voice.py`
   is the fullest example. Name the new one `tools/run_<subject>.py`. Its
   docstring says in plain words what the picture is, what was decided about the
   scene, and where the output goes.
3. **Include the standing rule blocks** (below) at the top of every prompt.
4. **Run it** with `python tools/run_<subject>.py`. Each take is a named key in a
   `TAKES` dict so several variants come out of one run.
5. **Composite anything small afterwards.** The model cannot draw Fujie at
   thumbnail size and invents nonsense Japanese for captions. Generate the scene
   with an empty phone screen / empty panel / empty caption strip, then paste the
   real artwork and real font over it with a `tools/build_*_screen.py` script.
6. **Cut the background out** with `python tools/cutout.py <file>` for studio-white
   subjects. It floods inward from the border so the character's own white belly
   survives, feathers the edge and trims the transparent margin. It refuses and
   warns if less than 2% of the image looks like background — that means the
   subject touches all four edges and the prompt needs more margin.
7. **Then look for trapped white.** The flood comes in from the edge, so any white
   the character's own outline shuts in is left behind: the daylight between a
   raised flipper and the tail, the loop of a handle, the gap inside a curled fin.
   It survives as a white patch that shows up the moment the picture is placed on
   the dark page, and it is easy to miss on a white preview — always check the
   cut-out against a dark background before accepting it. `tools/run_buddy_swim.py`
   has the fix worth copying: a trapped patch is near-white, big enough to see, and
   ringed by the black outline on nearly every side, whereas a shine on the belly
   is ringed by the character's own grey.
8. **Wire it into the site.** Add the file id and its Japanese/English captions to
   the right list in `promo/data.js`, make sure its folder is in `GALLERY_DIRS` in
   `tools/build_site.py` (or in `VERBATIM` if it must keep its transparency), then
   run `python tools/build_site.py`. The build fails loudly if a listed id has no
   file.
9. **Rebuild the offline copies** — `python tools/make_portable.py` for the game on
   its own, and `python tools/make_hub_portable.py` for the one-file copy of the
   whole studio that goes to the judges.

## The standing rule blocks

Copy these into the prompt. Each one exists because a batch was thrown away.

| Block | Says | Because |
|---|---|---|
| MASCOT RULE | Draw no mascot, character, logo or illustration anywhere | Anything the model draws has to be painted out; the real artwork is composited |
| TEXT RULE | No words, kanji, kana, letters, numbers, captions, signage, watermark | Screens came back full of invented nonsense Japanese |
| PEOPLE RULE | Everyone is Japanese — Japanese faces, features, black hair, Japanese hands | First attempt returned a European keeper |
| FISH RULE | Real photographed sturgeon: silver-grey, flat pointed snout, four barbels, bony scutes, upswept tail | The model reaches for sharks and dolphins |
| FARM RULE | Indoor recirculating hall with deep round fibreglass tanks — never an open-air pond, never an aquarium | The farm interior is a decided fact |

## Character rules

- Chibi Fujie has **one tail, two flippers, no teeth**.
- The official Fujie never smiles, is never hugged, and never has text laid over
  it. Only Chibi Fujie speaks.
- The swimming Chibi on the hub floats over the goods photographs **on purpose**.
  Never "fix" his path to avoid them.

## Common mistakes

| Mistake | What happens | Fix |
|---|---|---|
| Asking for the mascot in the scene | Off-model creature that must be painted out | Empty the space, composite after |
| Asking for a caption | Invented Japanese | Empty strip, real font after |
| Running cutout on a photographic scene | "only 0.4% detected as background — skipped" | Cutout is for studio-white subjects only |
| Checking a cut-out on a white page | White trapped inside the outline is invisible until it is on the dark site | Always view it on the dark background before accepting it |
| Adding art without touching `data.js` | Picture never appears on the site | Add the id and both captions |
| Adding an id with no file | `build_site.py` stops | Check the filename matches exactly |
| Regenerating approved art | Wasted run, inconsistent line | Check the approved list first |
