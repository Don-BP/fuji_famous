## Attach these three files

| File | What it is |
|---|---|
| `エントリーシート_記入済.docx` | The official entry sheet, filled in |
| `フジィは実在する_企画書.pptx` | The 30-slide proposal deck |
| `フジィスタジオ_オフライン版.html` | The whole studio offline — hub, timeline and game in one file (33 MB) |

The offline file is everything the live site has, in a single HTML that opens by
double-clicking, with no network and no other files beside it. The game is inside
it — "育ててみる" opens it over the page — so it does not need attaching separately.

It is 33 MB, so Gmail will offer to send it as a Google Drive link rather than an
attachment. Accept that, and set the sharing to "anyone with the link can view"
when Gmail prompts — otherwise the recipient gets a request-access screen.

`フジィを育てよう.html` (the game on its own, 6.9 MB) is still in this folder if a
smaller attachment is ever wanted, but it is not part of the submission — on its
own it is only one of the thirteen ideas.

## Note on the artwork

The official Fujie illustration is used **unmodified** throughout, exactly as the
character manual (ver 1.0, Article 7) requires — no reshaping, recolouring,
transparency, overlaid text, design changes, or added/removed elements.

「ちびフジィ」 is presented as a **proposed new second form** for a future
manual ver 2.0 — not as an alteration of the existing character. This distinction
is made explicitly on slide 9 of the deck.
