# Fuji Famous

Project workspace for the Fujie (フジィ) character contest entry.

Planning and specification work is driven by the
[Sigma Protocol](https://github.com/jasonawendo/sigma-protocol) 13-step methodology,
installed here for Claude Code.

## How to use it

In Claude Code, run the steps in order:

- `/step-0-environment-setup`
- `/step-1-ideation`
- `/step-2-architecture` … through `/step-13-skillpack-generator`

Or just say what you want to build and Claude will pick up the Sigma guide skill.

## What's in here

| Folder | What it holds |
|---|---|
| `.claude/commands/` | The 13 Sigma steps as slash commands |
| `.claude/skills/` | Sigma guide + Ralph loop skills |
| `docs/` | Documents the steps produce (PRDs, architecture, design system) |
| `ralph/` | Ralph autonomous implementation loop scripts |
| `sigma-protocol/` | Reference copy of the full methodology |
| `source-materials/` | Contest brief and character materials (local only, not published) |
